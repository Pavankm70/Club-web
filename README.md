# Club Management System

A full-stack **Club Management System** developed using **Java (Backend)** and **React (Frontend)**. The application provides separate panels for administrators and members, allowing efficient management of club members through a secure and user-friendly interface.

The project is containerized using **Docker** and deployed on **Render**.

---

## 📌 Project Overview

This system is designed to simplify club member management by providing role-based access for administrators and members.

The **Admin Panel** allows administrators to manage club members, while the **Member Panel** allows registered members to access their accounts using credentials provided by the administrator.

---

## ✨ Features

### 👨‍💼 Admin Panel

- Secure admin login using email and password
- Add new members
- Delete existing members
- Manage member information
- Control member access

### 👤 Member Panel

- Member login using credentials provided by the administrator
- Access personal account information
- User-friendly dashboard

### 🔐 Authentication

- Role-based login system
- Separate access for Admin and Members
- Credential-based authentication

### 🌐 Responsive User Interface

- Modern frontend developed using React
- Easy navigation and interactive design

### 🐳 Docker Support

- Application containerized using Docker
- Simplified deployment and environment management

### ☁️ Deployment

- Deployed on Render for online access and hosting
